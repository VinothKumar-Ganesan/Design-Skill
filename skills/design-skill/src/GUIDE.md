# Designing Skill — Beginner Guide & Checklist

This guide helps you learn basic design process steps and use the CLI starter to create simple templates.

## Quick process

1. Define the problem and target audience.
2. Write a short design brief.
3. Sketch ideas (paper or digital).
4. Create a low-fidelity prototype or static mock.
5. Iterate with feedback and produce final assets.

## Using the CLI

- Run `npm install` to install dependencies.
- Run `node index.js` (or `npm start`) to launch the interactive generator.
- Choose a template and follow the generated `checklist.md` inside the output folder.

## Beginner checklist (universal)

- [ ] Problem statement is clear
- [ ] Audience described
- [ ] 3 concept sketches produced
- [ ] One concept polished for presentation
- [ ] Exports created for required sizes/formats

## Tips

- Keep typography simple: use 1-2 typefaces.
- Limit your color palette to 3 colors for starters.
- Use spacing consistently — make a small scale (4/8/16px).
